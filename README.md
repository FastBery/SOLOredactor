# LittleMaid / SOLO 9 --- редактор сохранений

Небольшой инструмент для просмотра, расшифровки и редактирования файлов
сохранения **SOLO 9** (`.ss9`).

Программа рассчитана на Windows и не требует сторонних Python-библиотек.

Это всё vibecode. Сделано было для одного человека, чтобы помочь с СОЛО (хуета кнч)
В целом работает. Редактировать сейвы можно.
Для простых ребят, если вас ебут за скачанные сейвы СОЛО.

## Что умеет программа

Программа умеет:

-   читать `.ss9`;
-   проверять целостность сохранения;
-   показывать основную информацию о сейве;
-   расшифровывать `.ss9` в обычный XML;
-   собирать отредактированный XML обратно в рабочий `.ss9`;
-   пересчитывать CRC автоматически;
-   сохранять исходный сейв без изменений;
-   быстро изменять атрибуты пользователя;
-   изменять параметры отдельных попыток печати.

Главное: **не нужно вручную заниматься RC4, CRC или внутренней
структурой `.ss9`**. Программа делает это сама.

------------------------------------------------------------------------

## Подготовка

Положите файлы в одну папку:

``` text
LittleMaidTool/
├── solo_ss9_tool_local.py
├── littlemaid_backup_1.ss9
├── littlemaid_backup_2.ss9
├── littlemaid_backup_4.ss9
└── ...
```

Названия исходных сейвов должны соответствовать шаблону:

``` text
littlemaid_backup*.ss9
```

Например:

``` text
littlemaid_backup.ss9
littlemaid_backup_2.ss9
littlemaid_backup_4.ss9
```

### Python

Нужен Python 3.

Проверить установку:

``` powershell
python --version
```

Если команда показывает версию Python 3 --- всё готово.

# Самый простой способ работы

Если вы не хотите запоминать команды, **просто запустите программу без
аргументов**:

``` powershell
python solo_ss9_tool_local.py
```

Откроется меню:

``` text
==========================================================
        LittleMaid / SOLO 9 — редактор сейвов
==========================================================
  1. Посмотреть информацию о сейве
  2. Расшифровать сейв → XML для редактирования
  3. Собрать XML обратно → .ss9
  4. Проверить .ss9
  5. Быстро изменить параметр пользователя
  6. Выйти
```

Для обычного редактирования достаточно пунктов **2 → 3 → 4**.

# Редактирование XML

## Шаг 1. Расшифруйте сейв

В меню выберите:

``` text
2. Расшифровать сейв → XML для редактирования
```

Программа покажет найденные сейвы:

``` text
Какой сейв расшифровать?

  1. littlemaid_backup_1.ss9
  2. littlemaid_backup_2.ss9
  3. littlemaid_backup_4.ss9
  0. Отмена
```

Выберите нужный файл.

Например:

``` text
littlemaid_backup_4.ss9
```

Рядом с ним появится:

``` text
littlemaid_backup_4.xml
```

Исходный `.ss9` при этом **не изменяется**.

------------------------------------------------------------------------

## Шаг 2. Откройте XML

XML можно открыть практически любым текстовым редактором.

### Рекомендуется: VS Code

Если у вас уже установлен VS Code:

1.  откройте `littlemaid_backup_4.xml`;
2.  найдите нужный параметр;
3.  измените значение;
4.  сохраните `Ctrl+S`.

VS Code автоматически подсвечивает XML и позволяет сворачивать элементы.

### Также подойдут

-   Notepad++;
-   обычный Блокнот Windows для небольших изменений;
-   любой редактор, который не ломает XML.

**Не используйте Word или другие текстовые процессоры.**

# Сборка XML обратно в `.ss9`

После редактирования снова запустите:

``` powershell
python solo_ss9_tool_local.py
```

Выберите:

``` text
3. Собрать XML обратно → .ss9
```

Сначала программа попросит выбрать XML:

``` text
Выберите отредактированный XML:
```

Затем исходный `.ss9`, из которого нужно взять внутреннее имя и формат:

``` text
Выберите исходный .ss9, из которого взять формат:
```

Например:

``` text
XML:
    littlemaid_backup_4.xml

Исходный сейв:
    littlemaid_backup_4.ss9
```

Программа создаст:

``` text
littlemaid_backup_4_edited.ss9
```

Исходный файл:

``` text
littlemaid_backup_4.ss9
```

останется нетронутым.

После сборки программа автоматически проверит новый `.ss9`.

Если всё хорошо:

``` text
Status:      OK
```

------------------------------------------------------------------------

# Проверка готового сейва

Перед использованием рекомендуется проверить файл.

В меню:

``` text
4. Проверить .ss9
```

или из командной строки:

``` powershell
python solo_ss9_tool_local.py verify littlemaid_backup_4_edited.ss9
```

При корректном файле:

``` text
Stored CRC:  XXXXXXXX
Calc CRC:    XXXXXXXX
Status:      OK
```

`Stored CRC` и `Calc CRC` должны совпадать.

# Быстрое изменение параметров пользователя

Для некоторых простых изменений XML открывать вообще не нужно.

В меню выберите:

``` text
5. Быстро изменить параметр пользователя
```

Программа покажет параметры элемента `<user>`, например:

``` text
Доступные параметры:

  1. identifier = 24537
  2. surname = LittleMaid
  3. maxLesson = 15
  4. repeatLesson = 234
  5. repeatIter = 0
  ...
  9. lastExercise = 6.1
```

Выберите нужный параметр и введите новое значение.

Новый файл будет создан с суффиксом:

``` text
_edited.ss9
```

Например:

``` text
littlemaid_backup_4_edited.ss9
```

# Команды для опытных пользователей

Все команды можно использовать напрямую, без меню.

## Информация о сейве

``` powershell
python solo_ss9_tool_local.py inspect littlemaid_backup_4.ss9
```

Показывает:

-   размер файла;
-   внутреннее имя;
-   CRC;
-   данные пользователя;
-   количество уроков;
-   количество упражнений;
-   количество строк печати;
-   количество записей ошибок.

------------------------------------------------------------------------

## Расшифровать `.ss9` в XML

``` powershell
python solo_ss9_tool_local.py decrypt littlemaid_backup_4.ss9 littlemaid_backup_4.xml
```

------------------------------------------------------------------------

## Собрать `.ss9` из XML

``` powershell
python solo_ss9_tool_local.py encrypt littlemaid_backup_4.ss9 littlemaid_backup_4.xml littlemaid_backup_4_edited.ss9
```

Первый файл --- **исходный валидный `.ss9`**.

Второй --- XML после редактирования.

Третий --- новый `.ss9`.

------------------------------------------------------------------------

## Изменить атрибут пользователя

Например:

``` powershell
python solo_ss9_tool_local.py set-user littlemaid_backup_4.ss9 littlemaid_backup_4_edited.ss9 lastExercise 14.1
```

Или:

``` powershell
python solo_ss9_tool_local.py set-user littlemaid_backup_4.ss9 littlemaid_backup_4_edited.ss9 maxLesson 15
```

------------------------------------------------------------------------

## Изменить попытку печати

Формат:

``` powershell
python solo_ss9_tool_local.py set-typing SAVE OUTPUT LESSON EXERCISE ATTEMPT ATTRIBUTE=VALUE
```

Например:

``` powershell
python solo_ss9_tool_local.py set-typing littlemaid_backup_4.ss9 littlemaid_backup_4_edited.ss9 14 1 2 mark=5 left=0
```

Номер попытки начинается с `1`.

------------------------------------------------------------------------

# Где искать нужные значения в XML

После расшифровки XML можно искать элементы через `Ctrl+F`.

Например, пользовательские параметры находятся внутри:

``` xml
<user
    identifier="24537"
    surname="LittleMaid"
    maxLesson="15"
    ...
    lastExercise="6.1"
/>
```

Уроки находятся внутри:

``` xml
<course>
    <lesson number="...">
        ...
    </lesson>
</course>
```

Упражнения:

``` xml
<exercise number="...">
```

Попытки печати:

``` xml
<typing ...>
```

Ошибки:

``` xml
<error ...>
```

Не следует менять название корневого элемента:

``` xml
<SaveFile>
```

или удалять обязательные элементы, если вы не знаете, для чего они
нужны.

# Безопасная работа с сейвами

Всегда оставляйте оригинальный backup.

Хорошая структура:

``` text
LittleMaidTool/
├── solo_ss9_tool_local.py
│
├── backups/
│   ├── littlemaid_backup_1.ss9
│   └── littlemaid_backup_4.ss9
│
├── work/
│   └── littlemaid_backup_4.xml
│
└── output/
    └── littlemaid_backup_4_edited.ss9
```

Не редактируйте единственную копию сейва.

Сначала создайте новый файл:

``` text
littlemaid_backup_4_edited.ss9
```

проверьте его через `verify`, и только после этого используйте его в
SOLO.

# Если что-то пошло не так

### `RC4 decryption did not produce </SaveFile>`

Файл не распознан как поддерживаемый `.ss9`.

Проверьте, что это действительно сохранение SOLO 9 и что файл не был
повреждён.

### `CRC mismatch`

Сейв или XML были изменены таким образом, что контрольная сумма больше
не совпадает.

Для исходного сейва это может означать повреждение файла.

### `No <user> element found`

В сейве отсутствует ожидаемый элемент `<user>`.

### `Lesson ... not found`

Указанного урока нет в XML.

### XML не открывается после редактирования

Вероятно, была нарушена XML-структура. Верните последнее изменение или
откройте исходный `.xml` заново.

## Краткая памятка

Для большинства пользователей достаточно запомнить только это:

``` text
1. python solo_ss9_tool_local.py

2. Выбрать:
   "Расшифровать сейв → XML"

3. Открыть XML и изменить нужное значение.

4. Снова запустить программу.

5. Выбрать:
   "Собрать XML обратно → .ss9"

6. Проверить:
   "Status: OK"

7. Использовать *_edited.ss9 в SOLO.
```
